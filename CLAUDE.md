** Договорённости **

1) ВСЕГДА используй для добавления в шаблоны картинок компонент <Image/>, простой тэг img не допускается, потому что будут проблемы при деплое в Github pages.
2) НИКОГДА не агрегируй media запросы по брейкпоинтам, только по элементам.
3) Не используй записиь типа: 
  &__logo {
      &-img {}
  }

  Вложений через & может быть не больше 1го уровня! то есть данный пример должен выгляидть только так:

  &__logo {
      
  }
  &__logo-img {
    
  }

4) НИКОГДА не запускай `npx nuxi build`, `npx nuxi prepare` или `npx nuxi generate` без явного запроса. Для проверки работоспособности используй `npm run dev` — этого достаточно.
5) ВСЕ размеры, кроме border-radius мы делаем в единицах измерения rem
