# Подключение второго языка

Шаблон по умолчанию использует только русский язык. Переключатель в шапке скрыт, а проверка переводов автоматически при `npm run dev` и `npm run generate` не запускается. При этом реестр локалей, composable и валидатор сохранены.

## Добавление английского

1. Создайте английские словари с той же структурой, что у русских:
   - `data/common/en.ts` — общие данные сайта, включая `site`, навигацию и интерфейсные строки;
   - `data/pages/index/en.ts` — содержимое главной страницы.
2. Переведите текстовые значения, сохраняя ключи и структуру объектов и массивов.
3. В `data/locales.ts` импортируйте оба английских словаря, добавьте `en` в `SUPPORTED_LOCALES` и добавьте `en` в `localeData`, обернув данные в `applyTypography(..., 'en')`. Если английский должен открываться первым, измените `DEFAULT_LOCALE`.
4. Добавьте переключатель языка в `app/components/shared/Header.vue`. Используйте `useLocale()` и `setLocale()`; допустимые языки определяются `SUPPORTED_LOCALES`.
5. Запустите проверку вручную:

   ```bash
   npm run validate:i18n
   ```

   Валидатор сверяет пары файлов из `scripts/validate-i18n.mjs`, включая соответствие ключей, типов значений и длины массивов. Если добавляются новые локализованные наборы, внесите пары файлов в `localePairs`.

## Проверка перед запуском

Для проверки переводов перед каждым запуском разработки и генерацией добавьте в `package.json` lifecycle-скрипты:

```json
"predev": "npm run validate:i18n",
"pregenerate": "npm run validate:i18n"
```

Это включает проверку перед `npm run dev` и `npm run generate`. До добавления второго языка эти хуки оставлены выключенными, чтобы можно было спокойно работать с одним набором словарей.
